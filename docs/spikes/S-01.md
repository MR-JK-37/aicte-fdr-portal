# S-01 — Expo SDK / Node / React Native version matrix

**Status: PASS (doc-verified; device build not run in this environment — see note)**

## What was tested
Checked current official Expo documentation/changelog (not training-data memory, per CLAUDE.md "verify, don't recall") for:
1. The current stable Expo SDK version as of 2026-10-24.
2. The Node.js version it requires.
3. The React Native (and iOS/Android platform) version it pins.
4. Whether the repo's existing "Expo SDK 58" (set in commit `9651212`) is still current, or whether something newer has shipped.

## What was verified (official sources)
- **Expo SDK 58** is the current stable release, published **2026-10-15**, per the official Expo changelog (`https://expo.dev/changelog/sdk-58`) and the SDK index (`https://expo.dev/changelog`). The prior stable, SDK 57, shipped 2026-06-30 — SDK 58 supersedes it.
- SDK 58 is "built for iOS 27 and includes **React Native 0.88**." (official changelog text, SDK 58 page).
- Node.js requirement for Expo tooling with SDK 58: **Node.js 22.13+ on the 22 line, 24.3+ on the 24 line, or Node.js 26+**. (Node 20.x, which was the SDK 54 minimum, is no longer sufficient for SDK 58 tooling.)
- Android: compileSdkVersion/targetSdkVersion raised in step with SDK 58 (verify exact numbers against `docs.expo.dev/versions/v58.0.0/` at build time — the changelog page emphasizes iOS 27 more than Android API levels; re-check before pinning `android/build.gradle`).
- iOS: SDK 58 targets **iOS 27** as the newest platform; minimum supported iOS floor should be re-confirmed from `docs.expo.dev/versions/v58.0.0/` at build time (Expo typically supports N-2 iOS major versions).

## Repo state vs finding

Re-verify the exact Node version in CI images / `.nvmrc` / `package.json engines` against the 22.13+/24.3+/26+ requirement above — this is stricter than older guidance and may require updating CI runners.
