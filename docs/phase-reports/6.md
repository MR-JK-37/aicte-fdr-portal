## 1. What was built (Modules & Deliverables)

### 1.1 Universal Search & Saved Views (`F-17`, SPEC §11, §13.1–§13.2)
- **Component (`apps/web/src/components/SearchWorkspace.tsx`)**:
  - Universal text query across instrument numbers, institution names, AICTE codes, bank names, branch IFSCs, and UTR execution numbers.
  - Multi-attribute filter engine: status selection (`ACTIVE`, `EXPIRING`, `MATURED`, `RELEASE_REQUESTED`), bank filter, evidence level (`L1`, `L2`, `L3`), and amount thresholds.
  - Regulatory Saved View Presets:
    - *Expiring in $\le$ 30 Days*
    - *Pending Bank Confirmation (L1 Only)*
    - *High Value ($\ge$ ₹40 Lakhs)*
    - *Active & Statement Reconciled (L3)*
  - Dual sort order (maturity date, deposit amount).
  - One-click CSV export with auto-generated metadata headers.

### 1.2 Reports & Statutory Exports (`F-16`, SPEC §11)
- **Component (`apps/web/src/components/ReportsView.tsx`)**:
  - Executive financial summary cards (Total Custodial Deposit, Active Compliant Balance, Expiring / Deficit Risk Exposure).
  - Statutory Report Catalogue:
    - *Monthly Security Deposit Position (Table 1.4)*
    - *Maturity Schedule & Deficit Exposure*
    - *Reconciliation Discrepancy & Shortfall Register*
    - *Release Payout & UTR Execution Audit Summary*
  - On-Demand Report Generator: financial cycle selection (`FY 2026-27`), format toggle (`CSV`, `JSON`, `PDF`), and execution state.
  - Downloads History table with file sizes, cryptographic certification timestamps, and immediate client-side downloads.

### 1.3 Help, Support & DPDP Data Rights (`F-21`, `F-22`, SPEC §11, §15, §22)
- **Component (`apps/web/src/components/HelpAndRightsView.tsx`)**:
  - Approval Process Handbook (APH) guidance and FAQ search covering deposit tenures, joint custody, discrepancy resolution, and release workflows.
  - Interactive Grievance & Support Ticket submission form and status tracker with statutory priority flagging.
  - Digital Personal Data Protection (DPDP) Act 2023 portal:
    - Data principal rights tracker (`access_data`, `rectify_record`, `retention_review`, `nomination_update`) with statutory 30-day countdown.
    - Statutory Data Retention Schedule table enforcing WORM audit logs (indefinite), active deposits (7 years post-discharge), bank statements (10 years), and quarantine purge (30 days).

### 1.4 Admin Consoles & Connector Registry (`F-19`, SPEC §11, §12)
- **Component (`apps/web/src/components/AdminConsoleView.tsx`)**:
  - Integration & Connector Registry health monitoring: Scheduled Commercial Banks Direct API Gateway, PFMS Treasury Payout connector, DigiLocker Document Verification, FCM HTTP v1, and APNs HTTP/2.
  - Real-time diagnostic bar tracking: DB Scheduler Lease status, Audit Chain zero-tamper state, SSE Realtime Hub heartbeat, and Dead-Letter Queue (DLQ) held notices count.
  - Dead-Letter Queue inspector with failure reason disclosure, JSON payload preview, and single-click manual replay triggers.

### 1.5 Public Receipt Verification Gateway (`F-20`, SPEC §11, SPEC §18.1 Scenario 2)
- **Component (`apps/web/src/components/PublicReceiptVerification.tsx`)**:
  - Unauthenticated, rate-limited public verification page.
  - Receipt token and QR code input verification.
  - Verification against Ed25519 digital signature seal.
  - Privacy-preserving certified metadata disclosure: certified date, institution AICTE code, masked instrument number (`AXIS-FDR-XXXX-9201`), deposit amount in INR, and bank name without leaking internal account secrets or applicant private details.

### 1.6 Notification Center Drawer & Preferences (`F-14`, `F-15`, SPEC §10, §11)
- **Component (`apps/web/src/components/NotificationCenter.tsx`)**:
  - Slide-out glass drawer with unread counter.
  - Honest multi-stage badge display (`CREATED`, `QUEUED`, `PROVIDER_ACCEPTED`, `DEVICE_RECEIVED`, `OPENED`, `ACKNOWLEDGED`, `ACTIONED`).
  - Interactive mark as read, acknowledge, and deep link case navigation.
  - Preferences tab with Web Push (VAPID) and official email toggles, quiet hours configuration, and statutory non-suppression rule disclaimer.
  - Progressive Web App (PWA) install trigger button.

### 1.7 Global Command Palette (⌘K / Ctrl+K)
- **Component (`apps/web/src/components/CommandPalette.tsx`)**:
  - Keyboard-accessible modal listening on `⌘K` / `Ctrl+K`.
  - Instant fuzzy search across all portal tabs and regulatory workflows.
  - Full keyboard navigation with `ArrowUp`, `ArrowDown`, `Enter`, and `Escape`.

### 1.8 Top Navigation & Glass Design Polish (`apps/web/src/components/Navbar.tsx`, `App.tsx`)
- Apple-style Liquid Glass navigation layer (`DESIGN_SPEC.md §6/§13.2`) with 24px blur, saturation boost, and graceful opaque fallback.
- Integrated search button, notification bell with live unread badge, public verification toggle, Sim-clock controller, AI voice call modal, multi-lingual switcher (`en`, `hi`, `ta`), and role switcher.
