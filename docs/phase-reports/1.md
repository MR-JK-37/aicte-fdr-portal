## 1. What was built (Modules & Deliverables)

### 1.1 Identity, Authorisation & Governance (F-01, §8)
- **13-Role Permission Matrix**: Configured the authoritative role model (`AppRole`) and 26 permission verbs (`PermissionVerb`) matching SPEC §5 and MASTER_PROMPT §8.2.
- **Central Authorisation Engine (`app/authz.py`)**:
  - Implemented the single `authorise(principal, action, resource, context)` algorithm.
  - Enforced mandatory step-up MFA for privileged decision verbs (`approve_release`, `execute_release_record`, `manage_policy`, `manage_roles`, `configure_integrations`, `view_unmasked_identifiers`, `break_glass`).
  - Separation of duties (SoD) enforcement preventing maker from acting as checker or approver on the same case.
  - Delegation limits validated against numeric release amounts.
  - Role-scoped data filters and allow-list response serialization (`serialize_instrument` with `mask_identifier`).
- **Auth API & Session Management (`app/auth/`)**:
  - Implemented `/v1/auth/login`, `/v1/auth/logout`, `/v1/me`, `/v1/me/permissions`, and `/v1/auth/step-up`.
  - Secure HttpOnly `SameSite=Strict` cookie session (`fdr_session`) for web, Bearer JWT for mobile.
  - `get_current_principal` dependency dynamically verifies DB user status on every request, establishing transaction-scoped Postgres session GUCs for RLS.
- **Keycloak Realm Configuration (`infra/keycloak/fdr-realm.json`)**: Configured realm `aicte-fdr` with all 13 roles and OIDC clients for web (`fdr-web`) and mobile (`fdr-mobile`) with PKCE (S256).

### 1.2 Database & Row-Level Security (RLS, §8.5)
- **Postgres Session GUCs**: `set_app_context` sets `app.user_id`, `app.role`, `app.institution_id`, `app.role_scope`, and `app.assurance` via `set_config(..., true)` (SET LOCAL semantics).
- **Alembic Migration `e1a1f2b3c4d5`**:
  - Expanded `app_role` PostgreSQL enum to 13 roles.
  - Created tables: `idempotency_keys`, `outbox`, `feature_registry`, `connector_health_checks`, `role_permissions`, `audit_checkpoints`.
  - Added columns to `app_users`: `region_id`, `delegation_limit`, `mfa_enrolled`, `status`, `is_active`, `step_up_valid_until`, `row_version`.
  - Updated PostgreSQL RLS functions (`is_bureau_role`, `current_app_role_scope`, `current_app_assurance`) and applied strict tenant isolation policies.
  - Tested up and down migrations cleanly.

### 1.3 Audit Hash Chain & Checkpoints (F-18, §15.5)
- **Hash Chain**: Every `audit_log` row contains `prev_hash` committing to the preceding row's SHA-256 hash plus its own content. Trigger `audit_log_no_update` forbids UPDATE/DELETE.
- **Signed Checkpoints (`app/audit.py`)**: Periodic batch checkpoints signed with Ed25519 private key outside the database.
- **Auditor Verification Tool (`scripts/verify_audit_chain.py`)**: Verifies 100% hash chain integrity and validates Ed25519 signatures against the public key.

### 1.4 Feature & Connector Registry (F-19, §3)
- Feature registry table and admin API (`app/registry/router.py`) enforcing honest lifecycle states (`disabled | sandbox-only | production-enabled | degraded`).
- Transition to `production-enabled` requires an independent approver (maker-checker) and non-null acceptance evidence.

### 1.5 Cross-Cutting Resilience & Error Model (§15, §16)
- **Optimistic Concurrency (`app/concurrency.py`)**: `row_version` tracking with `409 STALE_VERSION` and `If-Match`/ETag support.
- **Problem+JSON Errors (`app/problem_json.py`)**: RFC 9457 error responses for 401, 403, 404, 409, 422, 429, 500, 503.
- **Correlation IDs (`app/correlation.py`)**: `CorrelationIdMiddleware` sets `X-Correlation-ID` on all requests and logs.
- **Transactional Outbox (`app/outbox/`)**: Producer, worker, and scheduler using `FOR UPDATE SKIP LOCKED`.
- **Idempotency (`app/idempotency/`)**: Middleware caching state-changing requests by key and SHA-256 body hash.

### 1.6 Packages & Design System Primitives (F-27, F-28, §13)
- **Packages**:
  - `packages/api-client`: OpenAPI client generated from FastAPI schema via openapi-typescript.
  - `packages/schemas`: Zod schemas matching backend models.
  - `packages/i18n`: Catalogues for English (authoritative), Hindi, and Tamil, with ICU formatting.
  - `packages/design-tokens`: CSS variables and TypeScript tokens for dark theme (`#050505` base, `#00eeff` cyan accent 14.2:1 contrast, `#3b0a6b` violet containers).
- **Web UI Primitives (`apps/web/src/design-system/`)**: Button, Card, EvidenceChip, Icon, Input, Sidebar, States, StatusBadge, Toolbar, theme.
- **Mobile UI Primitives (`apps/mobile/src/design-system/`)**: Button, Card, EvidenceChip, Icon, Input, States, StatusBadge, theme.

## 7. Risks & Mitigations
- **Postgres GUC Transaction Scoping**: Since `set_config(..., true)` is transaction-scoped, every transaction checked out from connection pools must explicitly set context. This is enforced by `get_current_principal` dependency on all authenticated routes and validated by `test_pool_isolation.py`.
