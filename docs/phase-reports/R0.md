# Stream R0 — Repair and boot (2026-10-24)

## What changed
- `apps/mobile/package.json`: `main` → `expo-router/entry`; added `expo-router`, `react-native-web`,
  `react-dom`, `@expo/metro-runtime`, `expo-constants`, `expo-linking`, `expo-font`,
  `react-native-safe-area-context`, `react-native-screens`; aligned `expo` to `~58.0.19` and
  `typescript` to `~6.0.3` (what `expo-doctor` expected for SDK 58).
- `apps/mobile/app.json`: added `scheme: "aictefdr"`, `web: { bundler: "metro", output: "single" }`,
  plugins `["expo-router", "expo-font"]` (auto-added by `expo install`); removed `RECORD_AUDIO`
  from Android `permissions` (dead leftover from the removed voice-call feature — nothing in
  `src/` requests it); removed the top-level `splash` key (no longer a valid SDK 58 schema field).
- `apps/mobile/app/_layout.tsx`, `apps/mobile/app/index.tsx`: new — minimal Expo Router boot shim
  (`Slot` + re-export of the existing `App.tsx`). This is **not** the final navigation; it exists
  only so `expo-router/entry` has a route tree to resolve. R1 removes the mock content it currently
  wraps; R6 replaces it with the real role-aware floating pill tab bar.
- `services/api/pyproject.toml`: added `[tool.pytest.ini_options]` with a `slow` marker.
- `services/api/tests/test_extraction_accuracy.py`: marked `@pytest.mark.slow` (does real PDF
  render + Tesseract OCR over 100 docs; not a hang, just ~5 minutes).
- `Makefile`: added `dev`, `dev-stop`, `api-test-slow`, `mobile-doctor` targets; `api-test` and
  `verify` now run `pytest -m "not slow"` by default.
- `docs/PLAN.md`, `docs/INVENTORY.md`, `docs/DECISIONS.md`: corrected from the PROMPT A versions
  (RLS false-negative fixed, extraction-accuracy "hang" reclassified as slow-not-broken, outbox
  scheduler test failures attributed to the correct cause).

- `npx expo-doctor` → **20/20 checks passed** (was 17/20: invalid `splash` schema field, missing
  peer deps `expo-constants`/`expo-linking`/`expo-font`, `expo`/`typescript` version mismatches —

  confirm the same failures reproduce deterministically (not flaky), consistent with the
  lock-contention explanation.

## Defects found/fixed
- **A-01 (mobile bundler) — FIXED**, proven by export + live bundle fetch.
- Dead `RECORD_AUDIO` permission (voice-feature leftover, part of A-04's native-config half) —
  removed.
- Invalid `app.json` `splash` key for SDK 58 — removed (cosmetic/schema only; R5/R6 will add the
  real v2 Lavender Ledger splash via whatever the then-current config shape requires).
- `pytest -m "not slow"` was not previously a thing — default `make verify` would have run the
  5-minute OCR benchmark every time; now opt-in via `make api-test-slow`.

## New risks / open items
- `app/_layout.tsx`/`app/index.tsx` currently wrap the **old mock** `App.tsx` (hard-coded FDRs,
  simulation controls, dark v1 theme) — this is intentional and temporary (R0 only needed the
  router to resolve to *something*), but it means the mobile app, right now, still shows every
  fake described in `docs/INVENTORY.md` §4. R1 must not skip mobile when it purges fakes.
- Test suite shares a database with a long-running live dev stack; 3 tests fail under that
  condition. Needs an isolated test DB/schema (R4 or R8), tracked in `docs/DECISIONS.md`.
- No Playwright-compatible browser could be installed in this sandbox (`sudo` unavailable for
  `playwright install --with-deps`). UI screenshot gates (G-23, G-24 design-contract tests, the
  six-scenario Playwright E2E runs) will need a different approach — check
  `mcp__claude-in-chrome` or another available browser automation path before R5/R6.
