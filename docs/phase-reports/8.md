## 1. What was built (Modules & Deliverables)

### 1.1 Multi-Provider AI/OCR Gateway (`app/llm_gateway/`)
- **Provider Registry (`registry.py`, `config/llm_providers.yaml`)**:
  - Typed specification for all providers: `groq`, `cerebras`, `gemini`, `openrouter`, `mistral`, `cloudflare_workers_ai`, `sarvam`, `ollama_local`.
  - Only live-verified providers are enabled; all unkeyed or unverifiable providers remain `verified: false` with `models: []`.
- **Token Bucket Rate Limiting (`resilience.py`)**:
  - Distributed fixed-window counters backed by Valkey/Redis (`llm_bucket:{provider}:{window}`).
  - Transparently skips rate-exhausted providers without blocking callers, falling over to the next configured provider in the route.
- **Circuit Breakers (`resilience.py`)**:
  - Tripping threshold: 3 consecutive failures (HTTP 429 rate limit, 5xx server errors, or timeouts).
  - Open duration: 60 seconds TTL in Redis (`llm_circuit:{provider}`).
  - Self-healing: closes immediately upon recorded successful probe.
- **Ordered Failover (`routing.py`)**:
  - Configured priority chains for `policy_qa`, `rag`, `extraction`, `ocr_field_structuring`, `translation`, and `translation_draft`.
  - Ordered cascade: primary fast LPU (`groq`) $\rightarrow$ wafer-scale backup (`cerebras`) $\rightarrow$ multimodal fallback (`gemini`) $\rightarrow$ zero-cost aggregator (`openrouter`) $\rightarrow$ local fallback $\rightarrow$ honest unavailable refusal.
- **Data Tier Isolation & Local Fallback (`routing.py`, `gateway.py`, `D-12`)**:
  - **Tier S (Sensitive Financial Data)**: Real FDR receipts, institution bank accounts, and amounts. Allowed processors: **strictly local model only (`ollama_local`)** with zero external network egress. External cloud providers are strictly prohibited.
  - **Tier P (Public Policy & UI Strings)**: Free external providers permitted for approved handbook text and synthetic UI strings with PII tokenization.
- **PII Redaction Layer (`redaction.py`)**:
  - Masking engine replacing PAN, Aadhaar, mobile numbers, IFSC codes, bank account numbers, and FDR instrument numbers with typed reversible tokens (`<<PAN_1>>`, `<<IFSC_1>>`) prior to external transmission.
- **Strict Schema Validation & Auto-Repair (`schema_validation.py`)**:
  - Enforces Pydantic model conformance on model JSON completions.
  - Triggers automated repair prompt on schema mismatch; falls back to cross-provider re-ask if repair fails.
- **Metadata-Only Audit Logging (`gateway.py`)**:
  - Every gateway attempt records to `agent_runs` table with `input_hash`, `tokens_in`, `tokens_out`, `latency_ms`, `provider`, `model`, and execution `status`. Raw prompts for Tier S are never persisted.
- **Global Kill Switch (`gateway.py`)**:
  - Evaluates `AI_GATEWAY_DISABLED=true` environment variable.
  - Instantly bypasses network dispatches and returns honest `"unavailable"` state across all features.

### 1.2 Bounded AI Assistance & Agents (`app/agents/`)
- **Compliance Policy Q&A (`rag.py`)**:
  - Semantic retrieval over Approval Process Handbook (APH) clause embeddings (`aph_clause_chunks`).
  - Cosine distance threshold gate (`MAX_DISTANCE_THRESHOLD = 0.6`): refuses out-of-domain questions with statutory notice: *"Not found in APH; refer to Regulation Bureau."*
  - **Citation Resolver (`resolve_citations`)**: Post-check verifying that every citation in the generated response resolves to a real stored clause. Any hallucinated clause number causes immediate refusal.
- **Gated Case Summaries (`case_summary.py`)**:
  - Summarizes authorized case fields for assigned scrutiny officers.
  - Strict Tier S restriction (local processing only per D-12).
  - **Record Reconciliation Post-Check**: Deterministically validates that all amounts, dates, and FDR numbers in the summary match the authorized database record.
  - Mandatory disclaimer: `[AI-generated assistance — verify against the record]`.
- **Machine-Translation Drafts (`translation.py`)**:
  - Translates public UI strings into Indian languages (Hindi, Tamil) for human review.
  - **ICU Placeholder Preservation Post-Check**: Asserts that variables like `{amount}` and `{instrument_number}` remain intact; corruptions fall back immediately to authoritative English text.
  - Saved as `status="machine_draft"`; production UI displays only `reviewed` strings.
- **Document Intelligence Extractor (`document_intelligence.py`)**:
  - Drop-in `FDRExtractor` implementation structuring OCR text into candidate fields without tool or write permissions.
- **Statutory Audio/Voice Policy (`M-21`)**:
  - Zero AI voice, speech, or calling simulations in production builds. Real-time, bounded, and real.
